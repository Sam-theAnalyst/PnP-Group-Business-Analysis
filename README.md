# Pick n Pay Group Financial and Economic Analysis

## Overview

This repository contains a comprehensive analysis of **Pick n Pay Group Ltd.**, combining both **financial** and **economic** perspectives to evaluate the company's overall performance and the external factors influencing its operations.

The project demonstrates the application of financial statement analysis, ratio analysis, macroeconomic analysis, and business research using publicly available company reports and economic data.

---

## Project Objectives

The primary objectives of this project are to:

* Assess Pick n Pay's financial performance over multiple reporting periods.
* Evaluate the company's profitability, liquidity, efficiency, and solvency.
* Examine how macroeconomic conditions influence business performance.
* Develop practical business insights through quantitative analysis.
* Demonstrate analytical and reporting skills relevant to finance, economics, and business analytics roles.

# Financial Analysis

The financial analysis evaluates Pick n Pay's financial health using ratio analysis and trend analysis based on the company's published Annual Financial Statements.

### Areas Analysed

### Profitability

* Return on Assets (ROA)
* Return on Equity (ROE)
* Gross Profit Margin
* Operating Profit Margin

### Liquidity/Solvency

* Current Ratio
* Debt Ratio

### Financial Analysis Objectives

* Measure financial performance
* Evaluate operational efficiency
* Assess liquidity position
* Analyse capital structure
* Identify financial trends over time

### Economic Analysis Objectives
